# Comprendre l'IA

Mini site statique (HTML/CSS pur, sans framework) créé dans le cadre d'une candidature à la Web@Academie. Il présente l'intelligence artificielle de façon accessible : son histoire, ses usages au quotidien et un formulaire de contact.

🔗 Déployé sur Vercel : [minisiteweb-academie.vercel.app](https://minisiteweb-academie.vercel.app)

## Pages

- `index.html` — Accueil
- `histoire.html` — Histoire de l'IA (frise chronologique)
- `usages.html` — Exemples concrets d'IA au quotidien
- `a-propos.html` — À propos et formulaire de contact
- `style.css` — Feuille de style commune

## Lancer le site en local

Aucune dépendance ni build : ouvrir `index.html` dans un navigateur, ou servir le dossier avec un serveur statique, par exemple :

```bash
npx serve .
```
